# Contributing to One Planet

Thank you for your interest in contributing to One Planet!

We welcome contributions from everyone. Whether you are fixing bugs, improving documentation, suggesting new features, or helping with tests—your input is highly valued.

### How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Describe your changes** clearly in your pull request. Reference any related issues.
3. **Write tests** for new features or bug fixes whenever possible.
4. **Follow our coding standards** (PEP8, flake8, black) and ensure all tests pass.
5. **All contributions are reviewed** by maintainers before merging.
6. **Be respectful and constructive** in all communications.

### Good First Issues

Check our [Issues](../../issues) labeled `good first issue` for beginner-friendly tasks.
